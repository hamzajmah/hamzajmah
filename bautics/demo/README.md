# Demo-Material

**Alle Inhalte in diesem Ordner sind erfunden.** Weder die Projekte
("SuedLink Baulos 4", "Ostküstenleitung Los 2") noch die Berichte, Zitate
oder Dateinamen stammen aus einem echten Vorgang. Sie dienen ausschließlich
der Vorführung.

| Datei | Inhalt |
|---|---|
| `dashboard.html` | Klickbarer Entwurf der Suite mit allen zehn Agenten (eine Datei, ohne Server) |
| `oberflaeche-echo.png` | Echte Oberfläche: Echo, Liste der Tagesberichte |
| `oberflaeche-echo-bericht.png` | Echte Oberfläche: Echo, ein Tagesbericht im Detail |
| `oberflaeche-mind.png` | Echte Oberfläche: Mind, Antwort mit Fundstellen |

Die drei PNG-Dateien zeigen die tatsächlich gebaute Anwendung
(`bautics/app`), nicht den Entwurf – aufgenommen mit erfundenen Daten.
